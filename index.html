Conectar el panel con tu agente

Se hace una sola vez en cada navegador. La clave queda guardada solo en este dispositivo.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: Panel agente. Expiración: la que prefieras (por ejemplo 1 año).
  3. En Repository access elige Only select repositories → agente-mercados.
  4. En Permissions → Repository permissions: Contents: Read and write y Actions: Read and write.
